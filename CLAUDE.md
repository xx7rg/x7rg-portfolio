# x7rG Portfolio

Personal portfolio of Rogério Gomes — Developer × Graphic Designer.

## Project instructions

- Use `x7rg-engineering` for architecture, implementation, debugging and technical decisions.
- Use `x7rg-portfolio` for visual direction, UX, motion and portfolio presentation.
- Use `frontend-design` for substantial interface design work.
- Prefer simple, robust and maintainable solutions over clever or overengineered ones.
- Inspect existing code before modifying it.
- Do not refactor or redesign unrelated working areas.
- Never fabricate portfolio information, clients, metrics, testimonials or experience.
- Do not install dependencies without a technical reason.
- Use MCP tools selectively and only when relevant.
- Use Context7 when current or version-specific external documentation is needed.
- Follow the local Next.js documentation requirement imported from `AGENTS.md`.
- Use 21st.dev for component research or inspiration when useful, then adapt results to the x7rG identity.
- Keep responses concise unless deeper architectural explanation is useful.
- Validate substantial changes before declaring them complete.

## Preferred direction

TypeScript, React, Next.js, Tailwind CSS and Motion when appropriate.

Prioritize:

1. Correctness
2. User experience
3. Maintainability
4. Accessibility
5. Performance
6. Visual quality
7. Technical novelty

Novelty must never come at the expense of the first six priorities.
