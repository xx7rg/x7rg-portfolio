# x7rG Portfolio

Portfólio pessoal de **Rogério Gomes** — Developer × Graphic Designer, sob a marca **x7rG Enterprise**.

Este repositório contém a implementação do site: um portfólio multilíngue (PT-BR / EN / ES) apresentando estudos de caso reais de projetos, identidade de marca e trajetória profissional.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- [React](https://react.dev) + TypeScript
- [Tailwind CSS](https://tailwindcss.com)
- [Motion](https://motion.dev)

## Desenvolvimento local

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Build de produção

```bash
npm run build
npm start
```

## Idiomas

O site é servido em três idiomas, cada um com sua própria rota:

- `/pt` — Português (padrão)
- `/en` — English
- `/es` — Español
